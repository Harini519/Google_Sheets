README - Web Application Mimicking Google Sheets

Project Overview: This web application mimics the core functionalities and user interface of Google Sheets. The goal is to implement a spreadsheet interface that supports basic mathematical and data quality functions, cell formatting, data entry, validation, and testing of various functionalities.

Key Features:

Spreadsheet Interface:

User interface closely resembling Google Sheets with a toolbar, formula bar, and cell structure.
Drag functionality for cells, formulas, and selections.
Basic cell formatting (bold, italics, font size, color).
Ability to add, delete, and resize rows and columns.
Mathematical Functions:

Functions for SUM, AVERAGE, MAX, MIN, and COUNT.
Data Quality Functions:

Functions for TRIM, UPPER, LOWER, REMOVE_DUPLICATES, and FIND_AND_REPLACE.
Data Entry and Validation:

Allow input of various data types (numbers, text, dates).
Basic data validation for numeric cells.
Testing:

A test environment where users can try out different functions and see results.
Bonus Features:

Additional mathematical functions.
Tech Stack:

Frontend: HTML, CSS, JavaScript
Libraries: Custom JavaScript for functionality
Evaluation Criteria:

Fidelity to Google Sheets UI.
Functionality and completeness of features.
Code maintainability and quality.
